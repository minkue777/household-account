## W4 후속: 보유종목 추가의 실패 초안

주식·코인·수동 항목은 저장 전에 입력을 지웠다가 catch에서 전부 복원하던 흐름을 없앴다. 기존 목록의 즉시 추가는 유지하고 입력 초안은 저장 중 보존한다. 성공 응답은 같은 편집 scope의 변경되지 않은 초안만 비운다. 사용자 입력이나 계좌가 바뀌면 그 새 초안에 성공·실패를 적용하지 않는다. 진행 상태도 계좌 편집 scope에 속하므로 이전 실패가 새 계좌의 진행 상태를 끝내지 않는다. 종료된 scope는 오류 팝업의 대상에서도 제외한다. 검색 hook의 사용하지 않는 restore API를 제거했다.

Web 타입 검사와 기존 첫 표시·검색·보유 manager 3파일 22개 통과. 신규 12개는 세 입력 종류 각각에서 실패 초안 보존→재시도 성공, 새 초안 입력 중 이전 성공/실패, 다른 계좌 저장 중 이전 실패를 검증한다. 로그: `TEMP/household-simplicity-holding-draft-20261005.log`.

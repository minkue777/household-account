## 발견과 설계

두 차트의 운영 호출자는 `stats/page.tsx` 하나입니다. 부모가 추이 선택과 callback을 항상 전달하므로 월별 차트의 내부 선택 상태·외부/내부 모드·fallback setter는 실제 사용되지 않습니다. 선택은 기존 부모가 계속 소유하며, 전체와 카테고리의 차트 데이터·버튼 생성을 같은 시리즈로 표현합니다. 조회·예산 기본값·사용자 토글 보존·가구 전환 초기화 책임은 부모에 남깁니다.

도넛 클릭 때 거래를 다시 필터링해 두 번째 인자로 전달하지만 부모는 선택 키만 받고 현재 원천에서 상세 목록을 계산합니다. callback을 선택 키만 전달하는 필수 계약으로 좁히고 중복 필터·범례 전달 함수를 제거합니다. 원본이 바뀌면 합계·비중과 실제 상세는 최신 값으로 갱신합니다.

보존할 동작은 월 경계·빈 중간 월의 0, 기간 안 모든 지출의 전체 합계, 활성 카테고리만 표시하는 추이, 미등록/비활성 카테고리도 포함하는 전체 합계, 도넛의 양수 항목·내림차순·전체 금액 기준 반올림 비중입니다. 선택을 모두 해제하면 안내를 표시하고 전체 선택을 강제하지 않습니다. 차트 색·선 두께·점·채움·애니메이션, 같은 입력의 참조 안정성과 최신 callback도 유지합니다.

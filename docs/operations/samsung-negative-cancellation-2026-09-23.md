# 삼성카드 음수 금액 취소 처리 — 2026-09-23

## 문제와 범위

삼성카드 주유 승인 100,000원, 취소 -100,000원, 실제 주유 승인 93,200원이 수신됐으나 취소만 파서에서 제외되어 두 승인이 원장에 남았다. Android 삼성 parser의 금액 행 정규식은 양수 표기만 허용했고 SMS parser는 `Ignored(NOT_COMPLETED_PAYMENT)`를 반환했다. 원문 제출 Application은 이를 거래 제출 없이 terminal 성공으로 끝냈다. 동일 원문에서 마이너스만 제거하면 cancellation 100,000원으로 해석되는 것을 수정 전에 확인했다.

이 변경은 서버의 삼성 금액 해석과 관련 문서·테스트에 한정한다. 운영 지출 복구나 과거 원문 재전송은 포함하지 않는다. 원문 fixture는 카드 번호·명의자·가맹점을 비식별 값으로 치환한다.

## 요구사항과 계약

- `PARSE-SAMSUNG-001`, `T-PARSE-002`: 삼성 `취소`·`승인취소`의 `100,000원`과 `-100,000원`은 모두 cancellation과 양의 정수 금액 100000으로 정규화한다. 카드 앱, 지원 SMS 앱 및 카카오톡이 공유하는 실제 삼성 parser에 적용한다.
- `IOS-015`, `T-PARSE-004`: iPhone Shortcut의 삼성 취소에도 같은 규칙을 적용한다. 승인 헤더의 음수는 취소로 추정하거나 양수 승인으로 바꾸지 않는다.
- 0·-0·범위 초과·잘못된 부호는 유효한 결제로 만들지 않는다. 누적 금액은 거래 금액으로 사용하지 않는다. 다른 카드사의 금액 해석은 변경하지 않는다.
- `CAN-003`, `CAN-007`: 정규화된 양수 취소액을 기존 Capture 경계에 전달한다. 금액·원 가맹점·카드가 완전히 일치하는 유일한 승인 lineage만 취소하며 다른 금액의 실제 주유 승인은 보존한다. 동일 입력 재전송은 멱등이다.
- 공개 raw notification·Shortcut HTTP·Capture envelope/응답 스키마와 fingerprint는 유지한다. 삼성·SMS parser version은 1.2.0, 카카오톡 복합 parser는 1.1.0, Shortcut parser는 1.4.0으로 표시한다. 일반 비결제 알림의 terminal 제외 정책도 이번 수정에서 변경하지 않는다.

## 상세 설계

Android 삼성 parser는 선택적 단일 `-`가 붙은 금액 행을 인식한다. 먼저 헤더로 승인·취소를 구분하고 취소일 때만 부호를 제거한 값을 기존 정수·상한 검증에 전달한다. 음수 승인과 0은 반환하지 않는다. SMS·카카오톡은 자체 정규식을 추가하지 않고 같은 삼성 parser를 사용한다.

Shortcut parser는 삼성 취소의 표준 layout에서만 금액 행의 숫자 바로 앞 단일 `-`를 제거한 뒤 기존 양수·안전 정수 검증을 적용한다. 카드·날짜·가맹점 검증과 다른 layout은 유지한다.

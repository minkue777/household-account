# Web·Android 성능 측정: 보고 전용

2026-09-17 사용자 요청에 따라 Web·Android 성능 측정은 소요 시간으로 PASS/FAIL을 판정하지 않습니다. 기존 시간값은 그래프의 CI 환경 참고선과 UX 목표로 유지합니다. 참고선을 초과해도 완전하고 유효한 측정이면 측정 완료이며, 성능 시간 때문에 CI를 실패시키지 않습니다.

- 측정 기능, 시작·종료 시점, 캐시 조건, 준비 실행과 본 표본 7회는 그대로입니다. 느린 표본도 제외하지 않습니다.
- JSON·Markdown·HTML과 CI 아티팩트 업로드를 유지합니다. [HTML 보고서 안내](./performance-html-report.md)에서 그래프와 개별 표본을 확인할 수 있습니다.
- 기능 E2E 오류, 측정 실행 실패, 표본 누락·중복·잘못된 값과 설정은 계속 실패합니다. `continue-on-error` 등으로 실행 오류를 숨기지 않습니다.
- 기존 테스트·작업의 실행 제한시간은 유지합니다. 기능 완료를 기다리다가 이 제한시간을 넘겨 측정 자체가 끝나지 못하면 측정 실패로 CI가 실패할 수 있습니다. 이는 성능 참고선 초과 판정과 다릅니다.
- Android 측정 대상 선정과 전체 기능 검사는 기존과 같습니다. Android 검사 대상이 아닌 변경에서 보고서가 생성되지 않는 것은 정책 전환으로 검사가 생략된 것이 아닙니다.

과거 실행의 통과·실패 기록과 날짜별 분석 문서는 당시 결과로 보존합니다. 기존 기록을 새 정책으로 재평가한 값을 새로운 CI 결과로 보고하지 않습니다.
